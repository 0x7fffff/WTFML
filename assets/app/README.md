# assets/app —— 应用图标

启动器的图标是「手写的 W」：一笔写成，下行重、上行轻，收笔一个小卷，无底。和品牌字的手写体（Dancing Script）同一路气质，线色是暮紫渐变，点缀一点暮光杏。

| 文件 | 用在哪 |
|---|---|
| `wtfml.ico` | exe 文件本身：资源管理器、固定到任务栏、Alt+Tab 里的那一枚。256/48/32/24/16 五档，由 `res/wtfml.rc` 编成资源（ID 1） |
| `wtfml-256.png` `wtfml-48.png` `wtfml-32.png` `wtfml-16.png` | 运行中的窗口：`ui/AppIcon.hpp` 把四档 `addFile` 进一个 QIcon，`src/main.cpp` 一次铺给所有顶层窗口 |
| `wtfml.svg` | 矢量源（路径绘制，没有 text、外链和字体依赖） |
| `wtfml-24.svg` | 导航轨左上角的品牌标：`ui/TitleBar` 读它的那条路径（只有 M/L/Z）自己填色，暮色雪山用原渐变，其余主题跟主题色走，并按身后实测底色（含自定义背景图）补到 3:1 对比度。取自设计稿 `W-script-24.svg` |

- 小尺寸是设计师单独画的专版，不是从 256 缩的：直接缩的话细线会断成虚点。48 用 48 专版，32 和 24 用 24 专版，16 用 16 专版（16px 去掉了起笔钩和收笔卷，只剩斜体的 W）。四张 PNG 和 `.ico` 里对应尺寸的帧逐像素一致。
- exe 资源里只放暮紫一版，不跟主题换色：固定到任务栏的图标取的是 exe 资源，运行时换色会和它对不上。
- 自绘标题栏（`ui/TitleBar`）不挂窗口图标；左上角那枚 W 是上表 `wtfml-24.svg` 的路径重新着色画的，不读 PNG。
- 换图标：盖掉同名的五个文件就行；`.ico` 换了之后 `res/wtfml.rc` 会自动重编（CMake 里挂了 `OBJECT_DEPENDS`，windres 不会自己盯 `.ico`）。
- 来源：设计稿第二版 `W-script`（三个方向里选中的一）。换图时用设计稿的 `.ico` 原样覆盖 `wtfml.ico`，再用 Pillow 从 `.ico` 取 256/48/32/16 帧存成四张 PNG，`wtfml.svg` 用设计稿的矢量主图。
