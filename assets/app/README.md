# assets/app —— 应用图标

启动器的图标是「湖上山影」：双峰、地平线、湖中倒影正好是一个 W，太阳落在两峰之间。和主页那幅暮紫山湖是同一画面，所以认得出是同一个程序。

| 文件 | 用在哪 |
|---|---|
| `wtfml.ico` | exe 文件本身：资源管理器、固定到任务栏、Alt+Tab 里的那一枚。256/48/32/24/16 五档，由 `res/wtfml.rc` 编成资源（ID 1） |
| `wtfml-256.png` `wtfml-48.png` `wtfml-32.png` `wtfml-16.png` | 运行中的窗口：`ui/AppIcon.hpp` 把四档 `addFile` 进一个 QIcon，`src/main.cpp` 一次铺给所有顶层窗口 |
| `wtfml.svg` | 矢量源（路径绘制，没有 text、外链和字体依赖） |

- 16px 和 32px 是**像素对齐版**，不是从 256 缩的：直接缩的话山与倒影之间那道缝只剩 0.7px，会连成一块。32px 以下看不出 W，只剩下浅上深下的一枚山形，这是这个图形在 16px 的极限。
- exe 资源里只放暮紫一版，不跟主题换色：固定到任务栏的图标取的是 exe 资源，运行时换色会和它对不上。
- 自绘标题栏（`ui/TitleBar`）里不画图标。
- 换图标：盖掉同名的五个文件就行；`.ico` 换了之后 `res/wtfml.rc` 会自动重编（CMake 里挂了 `OBJECT_DEPENDS`，windres 不会自己盯 `.ico`）。
- 配色和形状的来路见设计稿（`C-horizon`，三方案里选中的那一版）。
