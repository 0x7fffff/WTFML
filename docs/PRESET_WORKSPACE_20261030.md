# 预设工作区实现记录

日期：2026-10-30。以本轮用户确认的交互规则为准，不将离屏测试记为真机验收。

## 已实现

- 管理中的新建直接打开空白编辑器，不再先建立一份可安装的空预设。
- 左侧概览、游戏选项、按键、模组、资源包和数据包，编辑期间不分页面写盘。
- 概览编辑名称、图标和启用部分；部分禁用后仍保留内容。类型按已启用且非空的类别计算。
- 左下角保存为草稿、保存为预设、恢复到上次、全部清空。恢复/清空会丢失编辑时确认；清空保留名称和图标。
- 返回、顶端导航和窗口关闭经过统一离开检查：保存为草稿、保存为预设、不保存、取消。保存/校验失败留在编辑器。
- 草稿放在 `presets/drafts/<id>`，不参与安装候选；已发布预设保存草稿不会覆盖可用版本。
- 综合预设只展示一份公共记录，在相应类别中也能找到。安装时选择独立的类别投影；选择综合预设可勾选部分，无内容的部分禁用。
- 每个类别只选一份。资源包支持启用和顺序编辑，保留未涉及的现有包；缺少启用记录不自动改成全部开启。
- 实例维护的“另存为预设”提取到草稿，再进入编辑器；不提取模组配置和模组专有按键。
- 已启用本地模组通过 SHA-1 分批查询 Modrinth 身份，每批最多100项，查询串行且总截止45秒。未识别项保留待整理，不冒充兼容项目。
- 提取、资源复制和保存放在后台。资源导入采用带内容摘要的文件名；已存在但内容不同的目标拒绝覆盖。

## 数据与兼容

运行时的 `sections` 和 `modReferences` 仅包含启用部分；禁用内容在 `editorState` 中保留。旧加载器忽略编辑字段时仍只读取运行时清单。

综合预设的类别投影以 `internalComponent` 标记，列表不展示这些内部项。每次发布生成新的投影，避免失败的发布改变旧投影；旧投影暂保留，不做未经引用核对的清理。

编辑器仍复用原有应用计划、兼容性检查、备份和执行报告；草稿和编辑文档不直接作为安装指令。

## 仍需验收/补充

- 新编辑器整条原生操作流程及不同 DPI、极窄窗口。
- 更多真实实例提取样本和复杂综合预设安装、应用恢复场景；本轮自动检查不代替这些实包验收。
