## 修正与核对

- 实例树滚动恢复改为每棵树只有一个恢复状态和定时器。较新的请求替代旧请求；重新显示而范围不变时仍恢复；可见树重新布局后再核对位置；销毁取消回调。避免旧的 rangeChanged/单次回调在新位置设置后再次覆盖。
- 补充最新请求、复用已布局树、可见树重建和待恢复时销毁的回归，不改变当前选中的实例。
- Replay/结构等普通列表补回时间和大小第二行，测试读取实际可见文本的第二行，不再寻找不存在的自定义行控件。
- 原理图和配置页可以不创建无意义的占位图标；其它文件页保留原图标与缓存行为。
- 纹饰的 18 种复制材料与本地 Minecraft 1.21.11 客户端中 `data/minecraft/recipe/*_armor_trim_smithing_template.json` 的 C 项逐条比对，记录均为合法选项。镶铆记录铜块，当前配方也允许涂蜡铜块；未把单个合法选项写成全部可选项。
