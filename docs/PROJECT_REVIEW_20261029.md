# 项目检查与 UI 统一（2026-10-29）

检查基线为 `f16f50c`，包含最近的恢复响应性修改。本轮不清理游戏目录、开发计划或历史失败证据，不新增安装程序。

## 1. 体积：当前不是静态链接

Release 可执行文件直接导入 Qt6Core/Gui/Network/Widgets，以及 MinGW 的 libstdc++、libgcc、winpthread DLL，是动态部署。不能把安装目录总大小归因于静态链接。

对同一份正式构建的副本测量：

| 处理 | 字节 | 结果 |
| --- | ---: | --- |
| 原始 EXE | 16,106,889 | 原件 SHA-256 保持不变 |
| strip --strip-debug | 16,085,055 | 收益很小 |
| strip --strip-unneeded | 12,169,559 | 减少 24.45%，导入 DLL 清单相同 |

证据：`build/size-review-20261029-131250-622/report.json`。精简副本已使用隔离配置启动，并在真实窗口查看主页、下载页和模组筛选行；这不代替完整功能回归或独立部署包验证。

已有部署包的大项是软件 OpenGL 约 20.6 MB、QtGui 11.4 MB、QtCore 11.0 MB、QtWidgets 7.2 MB、D3Dcompiler 4.2 MB。资源文件没有显示出同量级浪费。

建议按顺序做：

1. 打包时只精简 EXE 副本，保留未精简构建用于排查；本轮仅提供测量脚本，没有静默替换发布产物。
2. 核对 windeployqt 的平台、图像插件与翻译目录。软件渲染依赖关系需在干净机器和低兼容 GPU 上验证后再决定删减，不能仅凭大小删除 DLL。
3. 单独比较 LTO、体积优化及节区回收的大小、冷启动和链接时间，不直接套到默认构建。
4. 安装程序和压缩下载包可以以后做；压缩并不减少运行所需依赖。

复测：`pwsh -NoProfile -File tools/measure-release-size.ps1`。每个外部工具限时 30 秒，输出到新的 build 子目录；原 EXE 不变。

参考：[Qt Windows 部署](https://doc.qt.io/qt-6/windows-deployment.html)。

## 2. 已实施的 UI 统一

- 普通控件统一到逻辑像素 12 / 14 / 18 / 28 四档：注释、正文、标题、主页主标题。保留字族和字重，实际显示缩放由 Qt 处理；最小普通文字为 12。日志内容的用户缩放和位图图标绘字是有意例外。
- 共用控件圆角 6、按钮 8、表面 12、分区 8；键盘焦点环按控件圆角内缩，避免形状错位。没有移除键盘焦点提示。
- 进入/面板动画统一 250ms，普通进度曲线使用 OutCubic，按压反馈 140–150ms。保留减少动态效果开关，增加 Windows 设置变化通知后的重新读取。
- 清理 src/ui 硬编码字符串里的中点分隔，改为斜杠或列表符号；不改写用户数据、历史记录和文件名。
- 去掉主页额外品牌眉题和口号、根页重复副标题、实例文件页常驻说明；必要操作说明放在提示中。数据包的目标存档提示保留。
- 缩短离线皮肤提示、搜索占位和底栏状态文字。没有把失败原因、风险确认和必要步骤说明作为“冗余”一并删除。
- 下载筛选行将“标签＋下拉框”作为一组布局，调整组内间距，修复字号统一后窗口最小宽度超过 900 的问题。补了类型标签与下拉框居中对齐判据，真实窗口复核未再出现游离标签。
- 后续按用户反馈将模组操作栏改为两列：检查更新/更新、复制/移动、删除/更多；启用菜单独占一行。侧栏 260 → 240px，内边距 16 → 12px，完整操作含义放入提示，移除常驻说明。

源码审计工具 `python tools/audit-ui-consistency.py --output build/project-review-20261029/ui-audit.json` 扫描 src/ui，不遍历游戏目录。结果：中点字符串 0，手工字号设置 5 处（公共入口、日志缩放、图标绘字）。这是静态启发式结果，不能证明拼接文案、动态内容、对比度和所有页面均符合要求。

## 4. 未完成与验收边界

- 退出 200ms 尚未统一：关闭/移除页面和模态生命周期要逐处接入，不能给进入动画套退出缓动冒充完成。
- 尚未统一弹窗/卡片/选中指示器的轻回弹；布局尺寸动画继续避免回弹。Qt Widgets 需要原生动画实现，不能直接使用浏览器 CSS 的 linear() 或 prefers-reduced-motion。
- 普通 QSS 按钮的悬停颜色仍有即时变化，尚未全部接入 120–180ms 过渡。已统一按压时长不代表所有 hover 完成。
- Windows 减少动态效果通知已接入，但这轮没有人工切换系统设置验收；其它平台的系统偏好检测仍待实现/验证。
- 新字号和间距尚未补跑完整的真实 100%/125%/150% 缩放、复杂内容窄屏、辅助功能和所有主题对比度矩阵。既有验收记录不因此失效，也不代替本轮新增视觉改动验收。
- 当前原生预览是隔离空配置，网络元数据请求受环境影响，不能作为真实下载、登录或整合包兼容验收。

参考：[Qt 样式表支持范围](https://doc.qt.io/qt-6/stylesheet-reference.html)、[Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion)。
