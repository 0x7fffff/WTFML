# 高级配色

设置 → 外观 → 高级配色中的「细分区域与控件颜色」默认收起。

- 控件角色：选择控件颜色角色，再选择颜色；「跟随主题」移除该项覆盖。
- 界面区域：分别调整底色、文字颜色和文字不透明度；不透明度可跟随全局。
- 遮罩没有文字，相关控件禁用。
- 「重置此区域配色」只清除当前区域的颜色和文字不透明度，不删除背景图，也不修改图片适配方式与不透明度。

编辑沿用现有主题控制器，立即生效并保存；现有主题导入、导出和恢复默认继续共用同一份规格。
没有自定义项时仍使用主题原有配色。控件角色与界面区域覆盖可能作用于同一界面，局部区域覆盖优先。

实现拆在 `ui/ThemeAdvancedEditor.*`，页面只负责放置入口，控制器负责颜色选择、生效和持久化。
控件测试覆盖枚举完整性、折叠、编辑、重置保留图片及非法索引；主窗口测试另核对真实控制器和设置保存。
这些自动化检查不替代多 DPI 真机验收。
