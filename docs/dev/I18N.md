## 2. 运行期怎么选语言

`ui/UiLanguage.hpp` 是唯一出处。

- 设置键 `General/Language`，取值 `system` / `zh_CN` / `en`，默认 `system`。
- `resolve(设置值, QLocale::system().uiLanguages())` 是纯函数：显式档直接用；`system` 时系统 UI
  语言里只要有中文（简繁、`zh-HK` 都算）就用 `zh_CN`，否则 `en`；认不出来的值按 `system`。
- `installTranslation()` 在 `src/main.cpp` 里调用一次：**验收档案建好之后、任何界面创建之前**
  （档案那一步会把 `QSettings` 指到隔离目录）。`zh_CN` 什么都不做；资源里没有 `.qm` 时记一句
  警告、界面退回中文。
- 改语言不即时生效：设置页弹提示卡「已保存为当前选择，重启启动器后生效」，两颗按钮
  「立即重启」「稍后」。`MainWindow::onLanguageChanged()` 里先 `DirectorySessionLock::releaseAll()`
  再 `QProcess::startDetached`（参数照抄本进程，`--acceptance-profile` 也在其中），最后 `quit()`；
  新进程起不来就重新取回目录锁并报「重启失败」。
- 目录锁的语义（同一游戏文件夹只允许一个窗口）见
  [DIRECTORY_SESSION_LOCK.md](../features/DIRECTORY_SESSION_LOCK.md)。

## 3. 构建管线

- CMake 里那一段在文件开头（`WTFML_I18N`）：`assets/i18n/wtfml_en.ts` → lrelease →
  `<构建目录>/i18n/wtfml_en.qm`；`wtfml_embed_translations(<target>)` 用 `qt_add_resources`
  把它按 `PREFIX /i18n` 编进目标。产品挂一次；要验英文界面的验证工程再挂一次（`ui_check`）。
- lrelease 从哪儿来，优先级：
  1. `-DWTFML_LRELEASE=<lrelease.exe 的完整路径>`；
  2. Qt6LinguistTools 提供的 `Qt6::lrelease`（动态 Qt 自带）；
  3. 自动找：当前 Qt 的 `bin`（按 `Qt6::qmake` 的位置推）、`QTDIR`、本机动态 Qt
     `D:/Qt/Qt/6.10.1/mingw_64/bin`。
- 三个都没有 → **配置阶段 FATAL_ERROR**。唯一跳过办法是显式 `-DWTFML_I18N=OFF`，那一份产物
  没有英文界面。
- 静态 Qt（`D:/Qt/static-6.10.1-mingw13/install`）只编了 qtbase，没有 LinguistTools，走第 3 条
  命中动态 Qt 那份 lrelease；`.qm` 编进 exe，静态单文件版不依赖外部文件。
- 只改 `.ts` 时不用重新配置，直接构建即可（lrelease 那一步会重跑）。

## 4. 怎么包字符串

- 有 `Q_OBJECT` 的类里：`tr("源文")`。
- `ui/` 里的界面类多半不是 `QObject`（`ui/` 不许 include `src/`），那里一律
  `QCoreApplication::translate("MainWindowUI", "源文")`。
- 上下文就是类名 / 模块名。同一个词有两种意思时才另起上下文；别每个文件发明一个新上下文，
  翻译表会碎成一片。
- 只存不翻、用的时候再翻：`QT_TR_NOOP("源文")`。
- 带参数的用 `tr("%1 个").arg(n)`，占位符 `%1` 原样保留。
- 不该翻的（日志、内部提示词、语言名自身）在行尾标 `// i18n-ignore`，整行不计入守卫。
- 新加的**用户可见中文**必须当场包起来，否则 `check-i18n` 直接红。

## 5. 刷新 .ts、写译文

```powershell
pwsh tools/i18n-update.ps1                    # 用本机动态 Qt 的 lupdate
pwsh tools/i18n-update.ps1 -Lupdate <路径>    # 或者自己指
```

它执行 `lupdate -locations none -no-obsolete src ui -ts assets/i18n/wtfml_en.ts`：新条目是
`type="unfinished"`，已有译文保留，源码里删掉的条目一并清掉。

- 译文用 Qt Linguist 打开 `assets/i18n/wtfml_en.ts` 填；也可以直接改 XML 里的 `<translation>`。
- 没翻的条目照样出 `.qm`（lrelease 只报个数），英文界面里显示源文中文。
- 术语等第 3 期：Minecraft 用官方英文名；`docs/dev/UI_COPY.md` 目前没有英文对照列，第 3 期先补那一列。

## 6. 守卫与基线

```powershell
pwsh tools/check-i18n.ps1                  # 有文件比基线多就失败（CI 的 repo-rules 会跑）
pwsh tools/check-i18n.ps1 -UpdateBaseline  # 包完一批字符串之后把基线改小
pwsh tools/check-i18n.ps1 -SelfTest        # 验守卫自己那几条判据
```

- 判据：`src/` 与 `ui/` 的 `.cpp/.hpp/.h` 里，字符串字面量含汉字或全角标点、又不在
  `tr(` / `translate(` / `QT_TR_NOOP(` 这类包装调用的括号里，算一处。注释里的、`#include`
  后面的文件名、标了 `// i18n-ignore` 的行都不算。
- 基线格式 `路径<TAB>处数`，**只许减不许增**。包完字符串 → `-UpdateBaseline` → 数字变小 →
  提交里看得见降了多少。第 2 期目标是 0。
- `tools/check-test-modules.ps1` 另有一条：`tests/support/SettingsIsolation.hpp` 必须仍把界面
  语言钉成 `zh_CN`。

## 7. 怎么在英文下看效果

- 起真 exe 必须隔离：`--acceptance-profile <临时目录>`。目录里要有 `acceptance-profile.json`
  （`format` 是 `wtfml-startup-acceptance/1`，`closeAfterMs` 2–120 秒）；`tools/dev-run.ps1
  -AcceptanceProfile` 会建好这一份。
- 想让它自己走一遍语言切换：档案里加 `"languageStep": "en"`。程序会切到设置页、拍「语言」那
  一行、真改一次下拉框、拍提示卡、点「立即重启」（`src/util/StartupAcceptance.hpp`）。新进程带
  同一个档案起来，再拍一张。产物：`settings-language-<pid>.png`、`language-prompt-<pid>.png`、
  两个 pid 的 `startup-<pid>.json`。
- 想直接起英文：在档案的 `<root>/settings/WTFML/WTFML.ini` 里写

  ```ini
  [%General]
  Language=en
  ```

  `General/Language` 在 INI 里的写法就是 `[%General]` 段；顶格 `[General]` 放的是**无分组**的键。
- 逻辑宽度小于 1024 时导航轨只画图标。截图前设 `QT_ENABLE_HIGHDPI_SCALING=0`，否则窄屏机器上
  永远拍不到带文字的导航轨。
- 测试一律钉 `zh_CN`（`tests/support/SettingsIsolation.hpp` 的守卫里写死），因为 CI 的 Windows
  是英文区域，跟随系统会让几千条中文断言一起变红。验英文界面的用例自己装 `QTranslator`，照
  `tests/ui_check/modules/UiLanguageChecks.cpp` 那份写。

## 8. 已知限制与坑

- `check-i18n` 按行扫：块注释有跨行状态，跨行字符串字面量没有；`QStringLiteral(QString(...))`
  这种拼出来的串算「没包」。会多报，不会漏报，多报就标 `// i18n-ignore` 或换写法。
- **默认 `system` 的后果**：非中文系统的用户现在会看到「导航英文、其余中文」的半成品。0.6.1
  发布前要么第 2、3 期做完，要么先把默认改成 `zh_CN`（`UiLanguage::resolve()` 里 `system` 那一档），
  不能就这么发。
- 导航图标按**序号**认（`ui/TitleBar.cpp` 的 `iconForIndex()`），顺序契约就是 `MainWindowUI`
  那五个 `addTab` 的先后。加语言不用动它；**重排页面**要同步改，`ui_check` 有断言盯着
  「英文下五颗都有图标」。
- 「简体中文」「English」这两个选项名是各自语言里的写法，永远不翻。
- `.ts` 里 3060 条 `unfinished` 是正常的（第 2 期没做），lrelease 不因此失败。
