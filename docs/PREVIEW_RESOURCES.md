# 纹饰预览资源

入口：工具箱 → 纹饰搭配。材料计算不需要资源；三维预览需要运行时载入纹理。

- 打开工具时后台按**客户端所属原版版本的发布时间**从新到旧尝试已安装客户端（最多 16 份），
  不按版本目录的 mtime（几十个版本常是同一天解压，按 mtime 会挑到旧客户端）；
  继承型/融合实例沿用 `jarOwnerId()` 找到实际原版 JAR。整条继承链上都读不出版本发布时间的
  （魔改整包自己拼的 json、手写的壳）排到最后：预览只取原版客户端里的纹理与调色板，
  装得再新也不许抢在原版前面。
- “读取已安装版本”可重新扫描；“选择本地 JAR”可手动载入其他目录的兼容客户端。
- 无可用本地资源时，可点“下载预览资源”，确认后从 Mojang 官方获取 Java 1.21.4 客户端包。
  下载量为 28,335,587 字节（约 27.0 MiB），不是几张纹理的大小；不安装实例、Java、依赖库或音效资源，不执行 JAR。
- 资源包只缓存到当前游戏目录 `cache/preview-resources/java-1.21.4-client.jar`，按官方 SHA-1 和大小校验。
  下次先查本地版本，没有可用本地资源再复用已校验缓存。切换游戏目录后旧异步结果不会混入新目录。
- 复用现有分段下载与可恢复缓存；支持取消、失败后重试，单次下载总期限 600 秒。
  归档读取单次 30 秒超时，并限制条目数量、展开体积与图片尺寸；不将归档内容解压到游戏目录。
- 可拖动旋转、滚轮缩放、双击复位；支持单件与四件套，纹饰使用资源内调色板，同材质使用 darker 调色板。
  皮甲为默认未染色，模型为固定站姿，不包含附魔光效。盔甲空心双面绘制，开口处可看到内侧纹理。
  头盔、胸甲、护腿、靴子四列分别选择盔甲材质、纹饰、纹饰材料；每件可不装备、可无纹饰。
  海龟壳只允许用于头盔，不会连带改变其他部位。材料按四个部位汇总，四列选择独立保存；
  旧单件/整套草稿首次恢复时会迁移到对应部位，旧控件仅作为隐藏的迁移适配器保留。
  预览复用当前玩家皮肤及纤细模型，切换账号/外观时同步刷新；盔甲仍双面绘制。
  工具栏与“记住输入”合并一行、压缩上边距，资源按钮位于右侧预览下方，预览限高 220–360。

## 兼容范围与限制

支持 Java 1.20 及以上的原版纹理布局：
- 1.20–1.21.1：`textures/models/armor`、`textures/trims/models/armor`、`textures/trims/color_palettes`；
- 1.21.2 起：装备层 `textures/entity/equipment/humanoid(_leggings)`、纹饰 `textures/trims/entity/humanoid(_leggings)`；
- 26.x：调色板再挪到 `textures/palettes/trim/` 与 `textures/palettes/trim_base`。

新路径在读取时折回旧名（逐字节比对过 1.21.1 ↔ 1.21.4，机器纹理与调色板完全相同；都是 64×32 / 8×1）。
涡流、镶铆需要包含它们的 1.21 客户端；树脂质需要 1.21.4 及以上的调色板。
缺少图案、格式不同或图片尺寸不支持时明确提示，不用伪造图案代替。
图案与材料名称照游戏 `zh_cn.json` 的 `trim_pattern` / `trim_material` 写（18 枚模板、11 种材料）。
高分辨率资源包、自定义装备模型、版本化筛选尚未实现。

## 验证

`wtfml.armor-trim` 使用代码生成的无版权纹理，覆盖模型层次、调色板、缺失资源、无效归档、按钮和布局。
可额外设置 `WTFML_TRIM_TEST_JAR` 指向自己的兼容客户端，验证真实纹理；
设置 `WTFML_TRIM_PREVIEW` 可把此运行时预览截图写入指定 PNG 路径。测试不自动下载官方素材。
