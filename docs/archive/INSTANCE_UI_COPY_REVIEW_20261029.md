# 实例管理文案复核（2026-10-29）

此前只处理了设置和预设的局部文案，没有覆盖完整的实例管理相关页面。本轮按页面和操作链复核，不以一次字符串扫描代替页面审阅。

## 本轮范围

| 页面/操作 | 处理 |
| --- | --- |
| 管理首页 | 移除导入按钮下方的教程；纠正仅支持 Modrinth 的旧说明，导入能力放入按钮提示 |
| 实例概览 | 收起重命名、收藏、导出、检查更新、复制和创建快照等重复说明；删除与还原后果保留可见 |
| 启动设置 | 移除全页“跟随全局/自定义”教程和重复的底部解释，保留控件与按需帮助 |
| 模组/资源/文件 | 精简启用、禁用、删除、详情和筛选提示，统一空状态；启用和禁用仍为直接按钮 |
| 存档与世界设置 | 统一备份/还原/规则编辑/读取失败文案；移除关于不同历史版本世界名称显示方式的泛化说明 |
| 服务器 | 精简新增、编辑、删除、加入和空状态提示，移除旧“临时占位”开发描述 |
| 实例更新 | 检查结果统一为“无法确认”，与更新中心实际状态文字及分组一致；保留失败原因与处理要求 |
| 复制/迁移 | 简化目标名称、进行中、可恢复等提示；运行/安装互斥、原件保护等行为不变 |

概览操作格统一顶部对齐，避免部分格子保留风险信息后按钮高低不一致。没有添加额外说明卡片、阴影或独立圆角参数。

## 保留的必要信息

- 删除实例进入回收站，清空后无法恢复。
- 还原覆盖当前文件、还原前备份及完成后校验。
- 原地升级完整快照、失败回滚、跨版本存档无法降级等原有确认信息。
- 模组声明未知、查询失败与必要前置未解决的实际原因。
- 导出整合包不包含存档和截图；完整数据应使用快照。

启动脚本旧提示声称导出文件包含正版令牌，已与当前实现核对并修正：脚本不持久化令牌，高级启动需在运行环境提供 `WTFML_MC_ACCESS_TOKEN`。本轮只修正提示，没有新增凭据存储或修改导出机制。

按“界面不摆冗余解释、能省就省”的口径再过一遍，只删字、不改控件结构、不动枚举与接线。处理的位置：
