## 尚在的大文件与职责

本轮扫描时 `MainWindow.cpp` 约 1.07 万行、`MainWindow.hpp` 约 3200 行；
`MainWindowUI.hpp`、`UiContentPagesChecks.cpp`、`InstanceSettingsDialog.cpp` 均仍在 3800–4100 行附近。
这些数值是源码规模参考，会随本轮改动变化，不是性能或完成指标。

下一步按状态所有权拆安装协调、服务端协调、资源更新、实例编辑状态和长寿命测试夹具；
`OverlayHost::execPage()` 及来路回调仍存在，导航后续按根页逐步迁移。
`wtfml.meta` 的读写仍集中在 VersionManager 的多个方法，带格式迁移边界的独立存储层仍值得做。
不以新建同名 Controller 或机械减少文件行数作为完成判据。

## 保留的不确定性

- Forge 服务端静默下载、测试探针的首次夹具/进程异常仍保留原现场，不以复测通过猜根因。
- 本轮没有重新检查 GitHub Actions；账单历史不能代替当前 CI 结论。
- 正版应用审核、真实账户、所有平台/网络、第三方杀毒、全部硬件与多 DPI 环境不由离屏测试替代。
- 通用文件批次恢复不等于序列化 Java 安装器、资源更新事务或临时部署器；只有接入并验证了上下文的入口才开放能力。

长篇实现历史移到对应文档。源码审阅发现的性能风险先测量，建议稿中的新能力先确认产品行为。
