## 用法与安全

先构建 `verify_instances`，测试目录必须全新或为空。两脚本总预算默认 240 秒，最多 900 秒。
仅终止自己创建的探针，输出日志和 JSON 永久保留；不自动清除失败现场。

```powershell
python tools/acceptance_p0_transactions.py --exe build/verification-mingw13/tests/verify_instances.exe --qt-bin D:/Qt/Qt/6.10.1/mingw_64/bin --work-dir build/my-new-p0-transactions
python tools/acceptance_p0_permissions.py --exe build/verification-mingw13/tests/verify_instances.exe --qt-bin D:/Qt/Qt/6.10.1/mingw_64/bin --work-dir build/my-new-p0-permissions
```

权限脚本只给自己新建的目录加当前 SID 的 deny，在 finally 移除该 SID 的本次 deny，**不重置整张 ACL**。
若系统强杀了权限脚本，应先看夹具目录和日志，再只对该夹具移除本次 deny；不要对真实游戏目录执行权限重置。

## 未覆盖范围：不伪造完成

写入期间才耗尽容量、断电/设备断连、不可中断系统 I/O、杀毒实时扫描与全规模关窗组合，
均不由 ACL、文件占用或 TerminateProcess 代替。独立 VHD 的已满卷验证见下；不等同写入中容量被并发耗尽。
真实 I/O 错误与权限拒绝的每一阶段笛卡尔积不宣称覆盖；本轮首先闭合可复现的进程/权限/慢盘路径。
