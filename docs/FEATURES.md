## 1. 产品边界

- Windows x64 桌面启动器，采用 C++23 + Qt 6 Widgets，仅支持 Windows。
- **没有 `.ui` 文件**，界面全部手写。
- 界面层与核心层分工：实际存在少量双向引用（`ui/` 有 6 处 include `src/` 模型与控制器，`src/` 有 45 个文件 include `ui/` 头文件；复杂业务、网络与文件操作由 `src/` 和 controller 层承载）。
- 产品 exe 为 GUI 子系统，不弹控制台；stdout/stderr 默认不可见，诊断信息写入 `<数据目录>/logs/wtfml.log`。验证工程为控制台程序。
- 数据目录为当前选中的游戏目录，非 exe 所在目录。
- 启动器自身状态和账户表保存在注册表 `HKCU\Software\WTFML`；令牌使用 Windows DPAPI 加密后落盘。
- 不记录用户明文密码；不将令牌、私有路径或本地凭据写入仓库、日志或错误报告。
- 已加载的 Minecraft access token 在启动器日志、游戏输出面板与导出报告中按实际值遮盖；stdout/stderr 各自跨块过滤，进程结束时残留的令牌前缀同步遮盖。普通日志不按 JWT 外形误删。正版启动脚本运行时需通过环境变量 `WTFML_MC_ACCESS_TOKEN` 提供令牌，缺失或格式不安全则拒绝启动。
- 影响操作结果或需要用户决定的失败必须在界面可见，不能仅写日志；可选外观资源获取失败可降级显示，关键步骤失败必须明确报错。
- 进度、速度、剩余时间、兼容性或操作结果均基于真实状态展示，未知即显示未知，失败即显示失败。
- 文件操作遵循可恢复原则：先备份/暂存，再原子替换；失败时保留原状态或明确报告已写入部分。

## 2. 界面骨架与交互

### 主窗口

- 左侧导航轨：品牌、五项导航、底部任务进度与工具箱入口（点它直接进工具箱页；游戏启动中、运行中或异常退出时，任务进度下方多出一行带状态圆点的运行状态，点开看运行中的实例）；宽 208，可手动折成 64 的图标轨，窗口窄于 1024 时自动折起。顶上 40 高的拖动条带最小化、最大化、关闭；标题文字可在设置中自定义，留空恢复默认。窗口里不在按钮、输入框、列表、可选文字上的空白处都能按住拖窗（贴边吸附照常），双击空白处最大化 / 还原；游戏日志窗和各独立窗口同样。
- 窗口最小 900×620。
- 应用图标是「手写的 W」（无底）（`assets/app/`）：exe 文件本身（资源管理器、固定到任务栏）由 `res/wtfml.rc` 编进资源，运行中的窗口（任务栏、Alt+Tab）用 qrc 里 16/32/48/256 四档 PNG 铺给所有顶层窗口；自绘标题栏不挂窗口图标，导航轨左上角的品牌标画同一个 W（跟主题着色，暮色雪山用原色；收起轨时只留 W）。
- 磨砂用 Win11 的系统背板（`DWMWA_SYSTEMBACKDROP_TYPE`：亚克力 3、云母 2），窗口里只铺一层半透明令牌色。系统默认只在窗口是「活动窗口」时画这层材质，一失焦就换成中性纯色（见 <https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic>）；本程序把每次 `WM_NCACTIVATE` 都按「激活」交给系统，DWM 便一直画激活态：**窗口失焦也保持模糊**，和聚焦时逐像素一样，客户区外那 1px 也不再变成一圈灰线。键盘焦点照常切换。设环境变量 `WTFML_KEEP_BACKDROP_ACTIVE=0` 回到系统默认（失焦退成纯色）。没有系统背板的系统（Win10 等）本来就落到风景底，不受影响。
- 着色层的 alpha 现算：取正文、次要字在背板可能落到的颜色（背后为纯黑、纯白和六个纯色时系统亚克力 / 云母合出来的颜色，按本机实测拟合，见 `ui/SystemBackdrop`）上都 ≥ 4.5:1 的最小值，「着色强度」只往上加（出厂 20%）。出厂时三主题都落在这个最小值：亚克力 / 云母档 暮色雪山 0.64、冰川碧湖 0.55、落日海崖 0.61；风景底档按模糊风景的明暗极值算，内置风景下 暮色雪山 0.51、冰川碧湖 0.71、落日海崖 0.73。
整窗铺主题场景图，开启「磨砂效果」时导航轨和面板为毛玻璃。
- 主体为「导航轨 + 一个正文面」架构：轨负责导航，正文区展示当前激活的主表面。
- 导航布局：同类独立功能使用可展开子项，内容较少的页面保留一级入口。
- 界面文案保持简洁、正式，直接说明操作与结果，不使用口语化叙述与中点分隔符。
- 主页、管理、下载、设置四个主选项卡；下载页和实例页内部包含各自的侧栏或分类栏。
- 主页大标题下面一行「每日一言」：一天一句、单行小字，超宽省略号；悬停显示「— 作者《出处》」。语种按本地日期定（英文 60%，其余为一言的中文或日文），当天不变；当天有缓存就不再请求，连不上先显示句子池 / 内置兜底里那一句。中文用文楷、纯英文用 Dancing Script、含假名用系统日文字体。设置 → 个性化 → 外观可关，关掉不发请求也不占位。细节见 [DAILY_QUOTE.md](features/DAILY_QUOTE.md)。
- 主页：左上大标题是一句问候（规则在 `src/util/HomeGreeting.cpp`）：第一次打开（没有「上次打开日期」记录且一个实例都没有）写「欢迎来到 WTFML」；没记录但有实例算升级上来的老用户，按时段问候；距上次打开满 14 天写「好久不见 {名字}」；其余按本地钟点 05–10 早上好、11–12 中午好、13–17 下午好、18–22 晚上好、23–04 夜深了，写「{问候} {名字}」，不带标点。名字和右上账号胶囊同一来源，没登录不带名字（「晚上好」）。启动、换账号 / 登录 / 退出、窗口重新激活时重算，不挂定时器。单行，名字太长只截名字（「晚上好 ThisIsAVer…」），问候保留；问候用文楷 Light（窄窗 40、宽窗 50），和名字之间空 0.4 个字高。名字（和「WTFML」）按整段判字体：全是字母、数字、下划线用 Dancing Script，字号放大 1.2 倍、字距 0；带中文（纯中文或中英混写）整段用文楷，不按字拆成两种；两种字都没有的字落到系统楷体。左下是当前实例的启动区。「名字 + 加载器与游戏版本」那一块可点，弹出毛玻璃实例切换弹层（顶部搜索、「最近」至多 5 个、「全部 · N」，底部「新建实例」去下载页、「管理全部实例」去管理页）；主按钮只做动作：启动游戏 / 停止游戏（当前实例在跑时）/ 安装中 N%，一个实例都没有时写「还没有实例」+「下载游戏」。右侧是当前皮肤人物（皮肤未就绪时显示内置默认皮肤）。底部实例带只摆真实例（没挑图标的实例按名字固定配一种颜色的方块），分「最近 / 收藏」两页：点卡片设为当前实例，悬停出的播放钮直接启动；「管理」去管理页。卡片从这一排的左缘一张挨一张摆，宽度跟实例名走（196 起、最多 320），名字放不下才省略；「当前」小字只标当前实例那一张。
- 当前实例：只要有实例就一定有一个当前实例（刷新时按 上次启动 → 上次手选 → 第一个 自动挑；当前那个没了（删掉、修复期间暂时滤掉）时顺延到同一位置的下一个，它回来了而用户期间没手选别的就换回它）；只有一个实例都没有时才是「未选择」。
- 账号入口在主页右上角：一颗圆头像 + 名字 + 一行小状态（「微软账号」/「离线」）的胶囊，底色极淡、不描边（浓度按主题定，风景再花名字也看得清），未登录时只写「登录」；它在拖动条下面，不压窗口按钮，900×620 也不挤标题。只在主页上有。点开毛玻璃账号弹层（从胶囊下面弹出）。未登录时是「未登录」+「登录」；已登录时列最后登录的三个账号（当前那个打勾，点别人即切换），下面是「添加账号」「管理账号与皮肤」「退出登录」（退出登录只清登录状态，账号留在列表里）。
- 常规设置、账号与外观、实例设置等采用覆盖层页面；游戏日志、直链下载和实例更新向导采用独立窗口。
- 覆盖层整页、任务详情和账号页打开时，导航轨、顶栏与内容区共用同一层磨砂风景底；对话框与提示卡只轻微压暗背景，风景仍透出。游戏日志窗同样铺磨砂底，标题旁徽标显示「运行中」或退出码（非 0 或崩溃时为红色）。
- 覆盖层单次仅激活一个主页面；新开页面时先收起可收起的旧页面。
- 键盘焦点清晰可见，Tab 顺序自上而下、从左到右；焦点环不改变控件自身几何尺寸。
- 输入类控件（输入框、搜索框、下拉框、数字框）的焦点分两档：鼠标点进来只把底色提亮一档、不画线；键盘 Tab / Backtab 到达才加一圈 3px 淡环。报错态把那圈换成危险色。
- 输入框宽度按内容定：名字类（实例名、预设名、配置名、存档名）留 24 个汉字、离线账号名 16 个字符、服务器地址 40 个字符、版本号 12~24 个字符，超出在框里滚动；窄窗只缩不溢出，旁边的按钮（添加、检测、刷新）紧跟输入框。路径、网址、JVM 参数、API 密钥、命令、哈希和搜索框保持整行拉伸。登记写法见 `ui/InputSizing.hpp`，`wtfml.input-widths` 扫描各页防回归。
- 数字框不画上下箭头，单位写在框内（MB / 秒 / 个 等），用滚轮、↑↓、PgUp / PgDn 调整；键入越界时回最近合法值。小整数（0–5）用「− 值 +」步进，内存这类大范围用滑块配小框。
- 下拉框和「文字 + 选项」的触发器都不带右侧小箭头：整块可点，触发器是胶囊形淡底、悬停加深。折叠行整行就是按钮，右侧写「展开 / 收起」。全应用不画右侧小箭头（∨ / › / 树的展开三角 / 底栏朝上的小箭头）：下载页版本树、资源树与管理页分组的可展开行行尾写「展开 / 收起」（13 号次要色）；进下一步的叶子行悬停时行尾写动词（版本树「安装」、资源树「下载」，强调色），不悬停不写。下载页搜索结果行距加大，展开的那一条连同版本子行铺成一张圆角淡底卡片，「收起」在卡片右上角，版本子行不画图标、文字对齐上面的资源名。返回按钮「‹ 返回」在左侧，不算此列。
- 设置页分段页签（启动 / 提示 / 个性化 / 下载）外面不画框，分组只靠底色差；那圈焦点环只在键盘操作（Tab / 方向键）后出现，鼠标点页签后不出现。
- 悬停提示（tooltip）自绘：磨砂玻璃底、圆角 8、内边距 6/10、字色随主题、无箭头无硬边；悬停 500ms 出现，收起后 1 秒内移到相邻控件立即出现，淡入 120ms 并上移 2px（「界面动效」关掉时不动）。提示只给图标按钮和条目用，文字按钮不出提示。
- 下拉弹层统一：磨砂玻璃底、圆角 14、内边距 6；项高 34、圆角 8、左右内边距 12，悬停淡底，选中是强调淡底加强调字（不画勾不画条）。最多露 8 项（约 300px），超出在弹层里滚轮 / 拖动 / 键盘滚动，右缘一条 3px 细条只在滚动时淡入、停 600ms 淡出，上下各 16px 渐隐；超过 15 项（旗帜图案、附魔）顶上多一条搜索框，键入只留匹配项。弹层从触发器下方 4px 淡入（150ms）。
- 浮层统一为同一块磨砂玻璃：下拉弹层、菜单 / 右键菜单、tooltip、账号弹层、工具页的工具切换浮层、实例设置的两个浮层。窗内自绘磨砂底 + 1px 亮边；Windows 11 且磨砂生效时另挂 DWM 瞬态亚克力，背后的是真模糊。
- 换页（主导航切页、整页打开与返回〔账号与外观、实例设置等，从弹层、页内按钮进都一样〕、设置页页签、下载页分类、实例设置分栏）的淡入只动内容本身（淡入 + 小幅上抬），底下写回的是换页前后都不变的那层底（含整窗磨砂的半透明着色），全程不垫任何不透明底色，真机亚克力 / 云母下磨砂不会闪成实心；任务中心整页开合的布局过渡同理。
- 进出主页时清晰风景层约 250ms 淡出 / 淡入（缓入缓出），露出 / 盖回整窗磨砂；导航轨不动，字色当下就换。淡到一半又切回去时从当前透明度接着走。「界面动效」关掉时直接切换。
- 整页上弹出提示时，提示背后仍是那一页和整窗磨砂：主页风景不回来、不透出底下的主页；换页过渡还在半路时先收到终点再弹。
- 动效默认开，只在设置里由「界面动效」开关控制，**不跟随 Windows 的「动画效果」**（系统那一档关掉时整套动效会被静默关掉）；关闭后几何尺寸、状态和交互结果与开启动效完全一致。

### 主题与尺寸

- 主题配置为应用级，不按窗口分别存储。
- 内置三个具名预设：暮色雪山（出厂默认，主题色 #B7B3EE）、冰川碧湖、落日海崖；另支持「跟随系统」。主题色默认跟着预设那一支走。
- 新安装的整窗材质是风景底（每套主题按自己的内置风景铺），≤ 2 线程的机器和旧版关过「磨砂效果」的仍出厂纯色；盘上选过材质的照原样读回，不受影响。
- 主题支持调整：主题色、文字不透明度、四个语义色、整份导入/导出及恢复默认。
- 背景图只有一张（铺满整窗，主页 / 管理 / 下载 / 设置都在它上面）；支持铺满、完整显示、拉伸、平铺及不透明度调节。
- 主题色、选中态、悬停态、焦点环、禁用态统一从 `ui/Theme` 的令牌与调色板派生。
- 选中样式统一为「强调淡底（accent-soft）+ 强调色字」，导航轨、列表、会话栏、实例设置分类都不画左侧竖条；导航轨选中块是圆角 10 的淡底，切换时滑动。
- 滚动条采用细线无槽底设计，把手为胶囊样式；文字型页面预留常驻滚动条空间，防止布局抖动。
- 间距遵循三档规范（页面 20 / 区块 16 / 控件 8）；圆角遵循四档规范（控件 4 / 按钮 6 / 主表面 8 / 小节 10）。
- 字阶四档（`Theme::TextRole`）：页标题 26 手写体 Light · 小节标题 16 半粗 · 正文 / 标签 / 按钮 / 导航 14 · 辅助 13（说明、单位、数值、分组头）。「安装」「创建」「应用」这类主按钮同样是正文 14 系统字（Medium），左右内边距 20、最小宽 88（`Theme::primaryButtonPadX()` / `primaryButtonMinWidth()`），图标档主按钮不吃这条。工具箱也收进这四档：结果标题与预览大字 16、MOTD 与等宽结果 14、说明与色点字母 13。例外：品牌 30、主页大标题 50（窄窗 40）与实例名 40、空状态大字 22。
- 正文用系统字（真桌面上是 Qt 取的系统界面字体，中文 Windows 为微软雅黑 UI，西文和数字也是它）。手写体只用在四处：品牌「WTFML」（Dancing Script）、主页大标题（纯英文名字和「WTFML」用 Dancing Script）与英文副句、页标题（「设置」「管理」、账号页、任务详情等）、空状态大字；这些控件挂 `wtfmlDisplay=true`，由 `Theme::markDisplay()` 统一设。导航、按钮、胶囊、分段、小节标题、表单、列表、菜单、下拉、tooltip、对话框标题与正文一律系统字。

### 高级配色

- 入口：设置 → 个性化 → 底部「高级」展开行 → 高级配色中的「细分区域与控件颜色」，默认折叠。
- 控件角色：支持单独指定控件角色的颜色，可随时点击「跟随主题」清除单项覆盖。
- 界面区域：支持分别调整各区域的底色、文字颜色和文字不透明度；不透明度支持跟随全局；遮罩区域禁用文字设置。
- 配色重置：「重置此区域配色」仅清除当前区域的颜色与文字不透明度，保留背景图及其适配方式与不透明度。
- 生效规则：配色修改即时生效并持久化；无自定义项时使用主题原有色彩；控件角色与局部区域覆盖发生重合时，局部区域覆盖优先级更高。
- 实现结构：实现位于 `ui/ThemeAdvancedEditor.*`，页面放置入口，由控制器负责颜色计算、实时应用与持久化；自动化测试覆盖枚举完整性、折叠状态、颜色编辑、重置保留背景图与异常索引防护。

## 5. 实例设置与文件

实例设置采用可滚动覆盖页，按功能划分子页：

- **概览与启动设置**：概览提供基本身份、最后启动时间与更新入口，没启动过写「从未启动」；启动设置管理 Java 路径、内存分配、JVM 参数与窗口模式（左边固定宽的行名、右边控件，「跟随全局」说明进悬停提示）；维护功能（复制、快照、修复）集中在维护页。
- **文件管理**：支持模组、资源包、光影、数据包、存档、原理图等分类管理；提供搜索、批量选择、删除、详情查看与打开目录；启停状态仅对支持该机制的类型生效。文件列表无边框，每行两行字（名字 + 大小·时间）居中，悬停 / 选中铺圆角淡底；行尾删除是次要色垃圾桶，悬停才变危险色。
- **文件页按需构建（优化打开耗时）**：
  - 实例设置对话框优化首次打开耗时：文件管理中的 8 个子文件页（InstanceFilesPage、配置文件编辑器、资源包页、存档世界设置等）仅在首次切换到对应页时才构建内部控件，构造阶段仅保留导航与堆叠外壳；
  - 提前到达的接线数据（如 `configFilePage()`、`resourcePackPage()`、图标、资源链接、可更新列表）先记账，建页时自动补灌；设置页打开耗时由 ~130 ms 降至 ~10 ms。
- **大列表窗口化与分帧渲染**：
  - 模组与存档等大列表先构建首批 80 行控件，其余每轮 120 行分帧延迟创建，首帧不卡顿（1000 行渲染约 362 ms）；
  - 支持可见范围外控件的回收与按需重建，并配备目录统计缓存。
- **配置编辑**：提供 `options.txt` 等文本配置的只读预览与修改；保存前执行格式校验，未修改行与未知键原样保留。
- **世界设置**：支持对单份存档调整游戏规则；修改前自动备份，保存后回读校验。
- **资源包**：启用与排序状态直接写入 `options.txt`，支持从排序模式切回文件管理。
- **服务器列表**：维护 `servers.dat` 的读写，支持添加、编辑、删除、延迟检测与直接连接；收藏列表独立保存在 `Servers/Favorites`，跨实例按服务器地址共享，不改动 `servers.dat` 原文件。主机名大小写与 IPv6 写法标准化；状态列仅展示延迟与在线人数，服务器版本与在线玩家浮动展示。
- **备份管理**：提供世界备份与完整实例快照；清单生成、打包与还原逻辑分离，产物明确可定位。
- **复制暂存机制**：复制实例先拷贝到 `versions/.wtfml-staging/<uuid>`，完整拷贝并重命名 jar/json/meta 成功后再原子发布；失败仅清理当前暂存，不影响已有数据。
- **原地升级保护**：扫描、副本校验与快照校验共用协作取消位；大文件按 1 MiB 块检查取消，取消或关窗停在最近安全点，源实例与用户文件保持完整可重试。
- **统一文件操作报告**：世界导入、迁移/升级副本、单文件拷贝与批量文件操作共用结构化报告：记录逐项结果、同名冲突策略（取消/跳过/覆盖）、可续暂存与失败原因；中断时可在任务中心选择「继续未完成操作」，失败时写出 `<报告>.failure.txt`；自动清理仅处理匹配自身 UUID 的暂存目录。
- **状态保护与互斥**：实例运行中或执行复制/备份/还原/安装期间，文件页禁用启用、禁用与删除操作；批量操作期间将实例标记为忙碌。
- **还原与中断恢复**：还原操作先校验候选目录再执行原子替换；启动或切换目录时保守恢复中断事务，源目录与候选目录同时存在时双方均予保留。游戏根目录整体移动时，通过升级 journal 根指纹重新验证后再恢复。
- **人工恢复目录**：在实例快照的「检查中断恢复」中提供「用旧目录替换（两份都保留）」，详见 [MANUAL_RECOVERY.md](features/MANUAL_RECOVERY.md)。
- **体检**：提供文件完整性校验报告，缺失文件、校验失败文件与未知文件分别列出，仅在具备可靠来源时提供修复方案。

文件页通用约束：

- 模组兼容性判定必须依赖平台元数据或本地文件解析依据。
- 删除、覆盖与移动操作必须二次确认；取消操作必须清理中间暂存。
- 执行操作前重新核对盘上文件清单，防止外部变动引发状态冲突。
- 所有路径检查严格防范 `..` 穿越、绝对路径逃逸及符号链接/junction 越界。

## 6. 实例预设

预设用于用户确认后的实例初始化。

- 预设按游戏设置、模组、资源包、数据包、光影包五类独立管理与存储；旧版复合预设保持既有结构。
- 每类支持选择一份预设；旧版预设保持原始数据，不静默变更。
- 游戏设置预设：对 `options.txt` 实施保序合并，覆盖按键、视距、GUI 缩放等选定项，保留未选中键与未知配置。
- 模组预设仅适用于已安装模组加载器的实例，安装前强制验证环境；纯原版与仅 OptiFine 环境拒绝应用。
- 模组预设严格区分项目、发行版、依赖与冲突；前置缺失或冲突时终止应用并明确告警。
- 资源包预设分别报告部署状态与启用状态。
- 数据包预设在无明确目标世界时保持待应用状态，不创建新世界。
- 预设管理支持新建、复制、重命名、删除、从实例提取、计划预览与应用；单个损坏预设不影响其余预设加载。
- 预设读取与清单解析均在后台异步线程执行，频繁切换仅保留最新请求；读取失败给出明确错误原因。
- 计划预览在后台执行只读计算，支持中途取消；实际应用前重新校验目标状态，不直接套用预览旧快照。
- 模组链接与平台 ID 必须解析为稳定项目身份，不支持未知站点及非数字 CurseForge ID。

详细执行边界参见 [PRESETS.md](features/PRESETS.md)。

- 无可信哈希的远端模组文件不写入；下载完成后必须校验再发布。

- 安装动作是任务中心里的一项，不另起一套进度系统。
- 直链和已接入的实例资源/安装文件批次可在任务中心暂停、继续；原件指纹及最终提交检查
  阻止覆盖外部改动。跨重启先补齐文件，命名安装需再次明确继续，才执行原选择的安装与预设。
  模组预设暂存与服务端文件下载也已接入；恢复核对原选择及目标，失效平台地址重新查询。
  文件补齐后的安装接续校验在后台执行，可取消、拦截重复继续，关闭窗口保留记录；
  校验通过后重新确认恢复条件，才执行安装接续。
  模组预设暂停后恢复时的目录核对也在后台进行，检查期间不重复恢复；外部修改仍要求重新预览。
  安装器/提交不可暂停，重启不自动运行 Java。范围与真机记录见 [恢复验收](archive/ACCEPTANCE_LOG.md)。
  具体范围与验证见 [下载恢复](features/HIGH_SPEED_DOWNLOAD.md)。
- 服务端安装支持原版、Paper、Purpur、Fabric、Quilt、Forge、NeoForge、Spigot（BuildTools）；服务端使用独立工作目录，首次启动需明确同意 EULA。

## 8. 整合包导入与导出

- 整合包 `overrides` 解压支持协作取消，解压过程定期检查取消信号并设置 900 秒安全上限；解压失败不删除既有用户目录。
- 支持常见整合包归档（ZIP、mrpack、CurseForge 导出包）导入；检测到系统 7-Zip 时自动解压 `.rar` / `.7z` 整合包，未安装 `7z.exe` 时给出明确安装指引。

- 覆盖文件严格实施路径安全检查，解压或复制异常时清理暂存，不生成损坏实例。
- 导出功能完整保留实例配置、模组清单与必要覆盖项；导出包中彻底剔除用户账号凭据。

- 针对 GTNH 2.8.4 等包含 MCLib AssetDirector 的整合包，导入成功后依据内置清单（`assets/assetdirector/known-sets.json`）自动预取首启所需 1368 个资源对象（约 122 MiB），完成校验后方结束导入，防止首启出现网络阻塞。

## 10. 任务中心与运行输出

- 底栏居中位置提供任务中心总入口；任务面板按进行中、已结束、待处理三类归集。
- 点左栏任务摘要先弹出约 400 宽的活动中心浮动面板（贴在摘要上方）：当前任务带进度与步骤，等待中可上移 / 下移 / 移除，已结束最近四条可重试、可一键清除；点外面、Esc 或再点一次摘要收起，「全部任务」进整页（筛选、搜索、历史、详情、拖拽排序）。面板里露出来的失败算已看过，摘要红点随之熄灭。
- 任务中心支持按状态筛选、关键字搜索及一键清理已结束记录（清理记录不删除对应文件）。
- 刷新机制：复用内容未改变的任务行控件，保持当前滚动位置；选中详情实时读取最新数据快照。
- 所有长耗时操作（下载、安装、复制、删除、备份、升级、完整性体检等）均统一登记为任务。
- 复合意图（如「更新实例」）仅展示单个父任务，准备核心、下载依赖等子操作以步骤和进度形式体现。
- 任务严格区分 `Pending / Running / Succeeded / Failed / Cancelled` 状态；取消任务不触发失败弹窗。
- 任务中心整页叠层交互：
  - 任务中心支持作为整页提示层（prompt overlay）叠在实例设置等页面之上，开关统一使用整页快照平滑转场；
  - 叠层开启期间保留原设置页与控件状态，再次点击任务中心按钮或关闭时平滑退回原设置页；
  - 面板集成状态筛选、关键字搜索与已结束任务清理工具栏。
- 文件操作异常中断后，详情页提供「继续未完成操作」；无法继续时输出失败报告文件路径。
- 游戏运行输出输出到专用日志窗口，不写入启动器主日志；高频下载进度事件同样不记入文件日志。
- 游戏异常退出在任务中心生成一条记录，并附带诊断分析与错误报告导出入口。

## 11. 设置

给要改设置的人看：设置页的结构、每一项在哪、保存规则。

### 结构

- 一级页（管理 / 下载 / 设置 / 工具箱目录与工具页）标题共用同一个左缘与上沿：距内容区左 38、上 22（`Theme::pageTitleInsetLeft()` / `pageTitleInsetTop()`），换页时标题不跳；智能体页没有页标题，不在此列。
- 页标题「设置」同一行右侧是搜索，下面一行是 4 个分段页签：**启动 / 提示 / 个性化 / 下载**，选中淡底滑块 200 ms 滑动，不画条。没有左侧索引栏和二级目录。
- 表单单栏，最宽 720，贴左，左缘与页标题同一条竖线。每个分组 = 16 px 半粗标题 + 一层极淡分组底（无边），行与行之间无缝，用缩进 14 px 的一像素底色差分隔。分组底不嵌套。

### 保存

- **没有「应用」按钮**：开关、下拉、滑块、步进器改完即存；输入框失焦或回车即存；JVM 参数框失焦或 Ctrl+Enter 即存（边打字不存，半条参数不会进命令行）。

### Java 管理与内存

- **Java 管理**：
  - 提供「自动（按版本匹配）」及各受支持 LTS 主版本（25 / 21 / 17 / 11 / 8）的手动指定；
  - 支持「下载所有缺少的 Java」（从 Adoptium 获取运行时安装至数据目录 `java/<主版本>`）与「检测已有 Java」（重新扫描本机系统路径）；
  - 支持「手动指定 java.exe…」：工作线程异步校验 Java 真实版本，确认无误后方写入配置，校验失败给出明确提示且不改动设置；手动指定的运行时标记为「（当前）」；
  - 首次进入设置页时的 Java 扫描在后台异步进行，目录变更使旧扫描缓存失效。
- **内存**：
  - 手动分配：调节 `MemorySlider` 或数字框，数值直接对应 `-Xmx`，`-Xms` 由启动器结合策略维护；
  - 自动分配：控件禁用并展示根据物理内存动态计算的推荐值，切换回手动模式时还原此前的手动配置；
  - 自动内存计算逻辑封装在 `GlobalJavaSettings::suggestXmxMb()` / `suggestXmsMb()` 中。
- **文件关联**：「设置…」把 `.nbt` / `.litematic` / `.schematic` / `.schem` / `.mrpack` 注册为 Windows 默认打开方式；`.jar` / `.zip` 只加入「打开方式」候选列表，不强占系统默认关联。跳过引导后仍可随时调用。

## 12. 工具箱

工具箱是主窗口的第六个选项卡，入口是导航轨底部的「工具箱」（不在顶上五项导航里）：点一下直接进工具箱页，没有弹出菜单；已经在工具箱页时再点一次回到目录。功能定位为即用即走的轻量辅助工具，不长期占用任务中心。

页面分两层：

- 目录页：自适应网格（最小列宽 240，900 宽两列、1280 宽三列），每格 36 图标 + 名称 + 一句用途（≤14 字），无卡片底，悬停淡底；右上角「记住输入」开关，关闭后清除已记住的输入。
- 工具页：页头是面包屑「工具箱 / 附魔助手」。「工具箱」回目录；点工具名弹出磨砂切换浮层（宽 236，复用 `GlassPopover`），直接换到别的工具。没有页内页签。
- 内容宽最大 880，贴左，左缘与页标题同一条竖线；各工具页在最小窗口 900×620 下没有横向滚动条、没有被裁的控件，信标、彩色文本、旗帜三页也没有纵向滚动条，窄时重排：内容宽 < 640 时附魔行折成两行，纹饰预览挪到输入下面，保存目录与文件名上下叠放，长的一行控件自动折行。数字框、下拉统一高 36。

当前内置工具（目录次序）：
- 附魔助手（计算铁砧经验惩罚与最优合成顺序；每行「附魔 · 等级 · 物品 · 已用次数」四个等高的框，物品下拉含「同上一件」）
- 彩色文本（MOTD、§ 文本、JSON、tellraw；左边输入与色码，右边预览与分段输出）
- 坐标换算（F3+C 剪贴板解析、区块边界、下界/主世界换算）

- SHA 校验（SHA-256 / SHA-1 / MD5 文件哈希比对）
- 信标计算（金字塔基座布局；左边结果，右边光柱配色：玻璃清单每行带色点，光柱示意放在柔和底台上）

### 盔甲纹饰搭配与预览资源

## 13. 网络、更新与诊断

- 通用 HTTP 网络请求基于 `HttpClient`；高速多段下载采用专用传输引擎。超时、重试、代理、Range 分段与错误归类遵循共用网络策略。
- 镜像源与代理设置仅调整请求路由，不降低下载安全校验标准。
- 更新中心支持组件检查更新、按项更新、忽略版本、固定版本与回滚上一版本。
- 更新执行前自动创建轻量回滚点，更新异常时保留原始文件；回滚点提供定向恢复能力。
- 启动诊断工具收集启动器版本、Java 状态、路径配置与关键日志摘要，不收集私有凭据与敏感令牌。
- 网络诊断工具（`WTFMLNetworkDiag.exe`）支持独立运行，可细分诊断 DNS 解析、TCP 握手、TLS 协商、HTTP 响应及数据传输各阶段异常。

## 14. 数据格式与安全规范

- 版本号、核心路径与配置键遵循唯一权威源原则，避免多头定义。
- 实例元数据 `wtfml.meta`、预设结构、安装事务记录与回滚数据严格保持向后兼容性。
- 所有关键文件写入均采用「写入临时文件 + 原子替换」机制，保障写入中断时不破坏已有文件。
- 注册表与配置项读取具备容错机制，缺失项或格式错误项不反向覆盖损坏有效配置。
- 路径防护约束：所有路径处理均严格校验，杜绝以下风险：
  - `..` 相对路径穿越；
  - 绝对路径越界逃逸；
  - 符号链接（symlink）或目录联接（junction）跳出目标根目录；
  - NTFS 备用数据流（ADS）或 Windows 保留设备名称（`CON`、`PRN`、`AUX` 等）。
- 外部输入安全性：版本 JSON 中的资源索引号与哈希值、外部传入的文件名在拼接本地路径前，统一通过安全字符集校验；外部图片解码前预先读取头部尺寸并设置分辨率上限，详见 [SECURITY_BOUNDARIES.md](features/SECURITY_BOUNDARIES.md)。
- 压缩处理与炸弹防御：
  - Windows 压缩后端采用扩展长路径格式，完整支持长路径、中文与特殊字符；
  - `ZipUtil` 压缩炸弹防护阈值：单条解压体积 ≤ 2 GiB，压缩比上限设为 10000（仅针对 > 1 MiB 的条目检测，避免 World region 等合法全零稀疏文件被误拦截），整批累计解压体积 ≤ 16 GiB。

**文件工具（1B，只针对锁定实例）**

- 实例锁定：第一次实例工具调用锁定当前主页实例并先持久化；锁定后不跟随主页切换；换游戏文件夹/实例删除返回 `InstanceUnavailable`；也可在「实例」下拉里预先选定或改回跟随主页，已有记录时切换需确认。
- `fs.list` 只返回目录元数据（数量/大小/是否截断），不返回文件名；`fs.listNames` 返回完整文件名清单，每次审批，最多 2000 项。
- `fs.read` 只读锁定实例内文本，默认 256 KB、最大 1 MB；二进制/凭据文件拒绝；返回 sha256 + `fileIdentityToken`；大文本写模型可读 artifact。
- `fs.write` 只允许 `config/**`、`defaultconfigs/**`、`options.txt`；必须带旧哈希与身份 token；每次审批；写前 DPAPI 备份、原子替换、写后回读；对象/内容变化拒绝。
- `artifact.read` 只读模型可读 artifact，每次重新脱敏；本地原始存档 id 模型不可读。
- 外发（D11）：日志/崩溃报告/锁定实例元数据/目录元数据自动读取，配置/完整文件名/其他文本逐次确认，凭据文件/凭据存储/二进制硬阻断，严格模式关闭自动读取；自动读取也提示"可能发送给当前模型服务"。
- 审批卡显示目标、摘要、diff/预览、备份提示、外发说明；工具卡显示待执行/执行中/完成/失败；审批请求不存"已批准"布尔，重启后作废并重新请求。
- 维护备份：`owner=agent` / `source=agent-session` / `sourceSessionId` / 实例 id / sha256；删除会话不删备份，只清理 Agent 自有备份。
