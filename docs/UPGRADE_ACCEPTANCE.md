# 实例升级：真机验收清单（U8 的未做部分）

> 状态：**待执行**。离屏判据已经覆盖九类组合、取消/重入、重名、空间预算、跨根拒绝、
> 报告分组、历史回溯；本清单只列"必须在真机/真实权限现场才能确认"的项。
> 每一项都写：前置、步骤、要记录什么。

## 0. 准备

- 一台 Windows 10/11 真机（不要用远程桌面的软件渲染），缩放先保持 **100%/125%/150% 各一轮**；
- 一个能随便折腾的游戏根（例如 `D:\wtfml-accept\`），里面放一份"来源实例"：
  存档 2 个、模组 5 个（其中 1 个不兼容目标版本）、配置、资源包 2 个（启用 1 个）、光影、
  截图、结构文件、`servers.dat` 各一份；
- 目标版本一个已安装（例如 1.21.4 + Fabric），确保能离线准备核心。

## 1. 原生 1000 × 750 布局

| 检查 | 做法 | 记录 |
| --- | --- | --- |
| 主页面完整显示 | 打开实例设置 → 维护 → 版本升级，窗口调到 1000×750 | 截图；九类是否三列、底部摘要是否固定 |
| 低分辨率/字体缩放可滚动 | 150% 缩放或更小窗口 | 截图；滚动时底部确认区是否始终可见 |
| 目标卡片联动 | 切换游戏版本/加载器 | 不支持的组合是否禁用或明确提示；旧报告是否立刻失效 |
| 名称校验即时 | 填空名、填已有实例名、填来源实例名 | 三种是否都当场拒绝且说得出原因 |

## 2. 兼容性报告（真机弹窗）

- 打开"兼容性报告…"：五组标题是否带条数、正常项默认折叠、搜索"mod"能否筛出、
  只看"不兼容"是否只剩那一组、必要项摘要数字是否与列表一致；
- 报告里点一条不兼容项：是否给出"依据"（本地声明/平台结果），而不是一句"不兼容"。

## 3. 权限与占用组合

| 场景 | 做法 | 期望 |
| --- | --- | --- |
| 目标目录只读 | 用 `icacls <目标父目录> /deny <用户>:(WD,AD)` 后开升级 | 明确失败并说明"写不进去"，源实例不变；收尾 `icacls /remove:d` |
| 源实例被别的进程占用 | 用另一个进程独占打开 `mods/*.jar`（或启动游戏） | 页面在确认前就挡住（"正在运行或被占用"），而不是跑到一半失败 |
| 目标名已被占用 | 手动建一个同名目录 | 拒绝且不动那一份 |
| 空间不足 | 在小容量分区（或 `spaceBudgetBytes` 很小时等价）试 | 拒绝在写快照/复制之前发生 |

## 4. 取消、重入、中断

- 复制过程中点取消：副本目录不出现、源实例不变、历史里留一条"已取消"；
- 取消之后立刻重试同一目标：能成功（暂存已收干净）；
- 复制中途强杀启动器：重开后"未完成操作"里能看到现场，继续或放弃都不会破坏源实例。

## 5. 历史与回滚

- 原地升级成功一次 → 更新记录里多一条：时间、1.20.1 → 1.21.4、成功、快照名；
- 同一条记录点"回滚上次原地升级…"：确认后回滚，当前版本被保留；
- 副本升级成功一次 → 历史里那条**没有快照**（"以源实例为回滚材料"），按钮不可点。

## 6. 跨根（当前明确不做）

- 把来源实例放到另一个游戏根下再试：应报"源实例不在这次事务的游戏目录里"，且**一个字节都不动**；
- 如果产品以后要支持跨根，先补"两个根的锁/空间/路径/历史归属"的设计，再改这一条。
