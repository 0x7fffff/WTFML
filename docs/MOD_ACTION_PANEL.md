# 模组管理操作栏：最终交互约定

2026-10-18 汇总：原稿位于仓库上一级《其余的一些设计.md》，后补示意图与原始对话；
本文件按用户随后接受的交互修正整理。早期“混选隐藏启用/禁用”“操作成功一律收起”不再作为实现依据。
本轮已落地模组页首版；资源包/数据包/光影页保留原布局，避免未经确认扩大改版范围。

## 布局与选择

- 左侧保留现有实例导航，中间宽列表，右侧操作栏约 260 逻辑像素。
- 无选择时收起；用户选择一项或多项后从右侧展开。不全局常驻，不遮挡顶部导航。
- 窄窗口以右侧抽屉显示，避免强撑窗口最小宽度；列表保持滚动位置和固定行高。
- 列表顶部选择工具行：`共 N 个模组 · 已选 M 项    全选 / 反选 / 清除选择`。
- 无选择时隐藏已选数量、禁用清除选择。首版沿用原有安全范围：全选/反选仅针对当前筛选结果；筛选隐藏的项退出选择，不暗中扩大操作范围，页面明确提示。
- 右栏 × 只收起，不清空选择；点击列表顶部“已选 M 项”重新展开。
- 启用/禁用、检查更新、复制成功后保留选择和面板，便于连续整理；失败保留。
- 删除/移动成功只移除实际处理成功的条目，失败项和其它仍存在的选中项保留。

## 操作层级

1. 状态：固定位置下拉“全部启用 / 全部禁用”；显示当前启用/禁用数量。
   已全部达到目标状态时禁用对应命令，不把整个集合当作单个开关。
2. 检查更新只读取；实际更新展示待更新清单及风险，二次确认后执行。
3. 复制到实例 / 移动到实例：明确区分保留来源和删除来源；移动只在目标校验成功后处理来源。
4. 删除独立展示并确认；首版只删模组文件，不附带“同时删除配置”复选框。
5. 更多：详情、文件位置、依赖/冲突、网页、导出列表，以及低频“反转每项启用状态”。
   不将反转与设置全开/全关混淆；不支持的能力不得伪装成成功。

固定面板、自动清理、测试实例/二分排查属于后续增强，不是首版前置。
配置清理未来单独预览归属，不能因为删除某个模组就删除共享配置目录。

## 实现及验收要点

复用既有模组动作，新增按需 `ContextActionPanel` 容器和明确的选择/收起状态；
不重写下载、更新和文件迁移执行器。列表顶部负责选择，右栏负责动作。
切换实例时清理旧上下文，异步返回不得修改另一实例；文件变动后按稳定文件身份保留选择。
覆盖混选、部分失败、筛选后批量操作、连续收起/展开、窄窗、键盘与多 DPI。

## 2026-10-18 实现记录

- 模组页顶部常驻选择工具行；右栏 260px，内容宽度不足 740px 时改用覆盖抽屉，不抬高窗口最小宽度。
- 关闭只收起，点击“已选”恢复；选择变化自动展开，文件改名刷新按稳定身份保留选择，删除/移动后仅消失的文件退出选择。
- 固定状态菜单全部启用/禁用，不适用命令禁用；更多中提供逐项反转、单项详情、打开目录、复制模组清单。
- 检查更新复用现有检测器，右栏仅检查选中项（沿用跳过禁用文件的规则）；局部检测合并结果，不清除其它文件的更新目标或固定版本。全实例入口不变。
- 更新确认显示目标版本、文件名、游戏版本及加载器，仅提交清单内可更新项；确认期间上下文或目标版本变化会中止。沿用原回滚/下载执行器。
- 复制/移动复用 TransferApply 的拒绝链接、不覆盖校验；确认兼容提示，运行/安装实例拒绝处理；逐文件 SHA-256 校验，移动只有目标验证成功且源未改变才删除源文件；不处理配置。
- 开合复用统一合成快照动画，避免逐帧拉伸文字；窄窗仍可滚动列表。
- 更多已补项目网页入口，使用已识别平台与项目 slug，未知资源不猜测链接。
- 待增强：当前版本→目标版本完整差异与依赖变化预览、依赖冲突汇总、迁移长任务异步化/取消、跨版本自动下载适配模组，以及实机多 DPI/大量条目验收。当前不会伪造兼容或自动适配结果。
